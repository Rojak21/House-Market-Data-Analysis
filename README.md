# Home Market Overview

An interactive **Power BI dashboard** built using **Google BigQuery** to analyze housing market data, sales performance, pricing trends, regional differences, and house-type characteristics. The dashboard uses interactive visuals and filters to help explore housing sales and pricing patterns.

### 🏠 Home Market Overview

Provides an overview of housing market trends, including sales prices, regional price changes, offer vs. purchase prices, and YOY sales growth.
<img src="https://github.com/Rojak21/House-Market-Data-Analysis/blob/main/Screenshots/House%20Market%20Overview.png" />

### 📊 Sales Performance

Analyzes sales performance across regions, purchase prices, sales trends, and price-per-square-meter metrics.
<img src="https://github.com/Rojak21/House-Market-Data-Analysis/blob/main/Screenshots/Sales%20Performance.png" />


### 🏡 House Type Analysis

Compares different house types based on offer price, purchase price, SQM price, and other housing characteristics using interactive filters.
